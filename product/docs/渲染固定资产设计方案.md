## 二、固定资产设计

### 1. CSS 模板体系（render/templates/*.css）

内置 3 种风格 + 默认兼容：

| 模板 ID | 风格定位 | 视觉特征 |
|---|---|---|
| classic | 经典素雅（对标 moderncv banking 精神） | 衬线标题、细分隔线、黑白灰、单栏 |
| modern | 现代双栏（对标 reactive-resume 双栏） | 左侧深色信息栏（联系方式/技能）、右侧内容、教育蓝点缀 |
| minimal | 极简单栏（对标极简风） | 大留白、细字重、无边框、克制的强调色 |

设计规范：
- 全部支持 A4 打印：`@page { size: A4; margin: 18mm 16mm; }` + `print-color-adjust: exact`
- 中文字体栈：`'PingFang SC','Microsoft YaHei','SimSun',serif` / 标题衬线 `'Noto Serif SC','SimSun',serif`
- 变量驱动：`:root { --accent; --text; --muted; --border; }`——用户自定义 CSS 只需覆盖变量即可换肤
- 结构类名契约（build_html 输出固定类名，模板只写样式）：`.resume / .r-header / .r-title / .r-adapt / .r-exp / .r-claim / .r-evidence / .r-subtitle`

### 2. 用户自定义 CSS

- /api/export 接受 `custom_css`（字符串）或 `custom_css_path`——自定义样式覆盖内置模板（合并而非替换：内置提供结构基础，自定义变量/样式追加其后）

### 3. render_pdf.py 改造

```python
render_markdown_to_pdf(resume_md, out_path, template="classic", custom_css=None)
build_html(resume_md, template="classic", custom_css=None)  # 多模板加载
```

模板加载顺序：custom_css（最高优先）→ render/templates/{template}.css → resume.css（兜底）

### 4. 前端模板示例

- 新增 /api/templates：返回模板清单 {id, name, description, accent, layout} 
- 前端（步骤⑥）加模板选择卡片组：每卡片用微缩 CSS 预览（小尺寸版式模拟：标题条/双栏块），选中后导出传 template 参数

### 5. 与 template_registry.py 的关系

- template_registry.py（MCP list_templates/register_template）——管理**生成模板**（LaTeX/HTML/MD 输出格式）
- render 内模板目录——管理**PDF 渲染样式**（CSS）
- 两者互补：registry 决定"简历的结构格式"，render 模板决定"PDF 的视觉样式"。互不合并（职责单一）。
