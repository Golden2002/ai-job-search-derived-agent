# 04_通用简历 · 需求规格说明书 v2.0

> 第一波次交付物（2026-08-23）· 基于双基线能力清单（03 号文档·主/辅两份）+ 顶尖标准对标表（02 号文档）
> 版本 v2.0（2026-08-23 · 基于波次 2 方案更新）：需求完整、标准明确、可落地；已升级 v2.0

## 1. 项目定位

**JD 精准匹配、STAR 量化表达、ATS 兼容、双 Agent 质量闭环**的通用简历制作工具。
双基线分层融合：主基线（ai-job-search-derived-agent）= 工程框架与工作流引擎层；辅助基线（medical-resume-agent）= 经历处理方法论与质量控制层。

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 生成单份简历 <2 分钟（无 LLM 排队） |
| 安全 | 简历隐私数据本地处理；API 密钥不入库 |
| 兼容 | Python 3.10+；独立可运行；LaTeX 可降级（无 TeX 环境用 WeasyPrint） |
| 可移植 | 双基线模块解耦（引擎层不依赖内核层实现细节，经接口对接） |
