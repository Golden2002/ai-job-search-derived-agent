# 《基线能力清单》— medical-resume-agent（辅助基线）

**基线位置**：`D:\项目\04_通用简历\baseline_aux\`
**项目名**：medical-career-agent / 「医学生的第一个简历助手」/ Skill Lite：Medical Resume Skill
**定位**：面向医学生的「经历→事实→能力证据→定向表达」本地化简历工具，包含**网页体验版（Flask + 前端）**与**Skill Lite（Codex/Claude 提示词工作流包）**双入口。核心原则：**先确认事实，再翻译表达**；未确认信息不升级、不编造。
