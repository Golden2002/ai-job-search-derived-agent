## 3. 融合接口契约（L2 ↔ L3 对接）

```
ExperienceKernelPort（内核层暴露，引擎层只调此接口）：
  draft_experience(raw_text) -> CanonicalExperience + unknowns + questions
  confirm_facts(facts, evidence) -> CanonicalExperience(confirmed)
  compose_bullets(experience, role_pack, tier) -> BulletClaim[](gate_status=ready|needs_confirmation|rejected)
  rewrite_tier(claim, tier) -> BulletClaim[](rewrite_source_traceability)
  validate_claim(claim) -> {ready, checks[]}

引擎层调用点：
  DrafterReviewer.draft() → kernel.draft_experience() + kernel.compose_bullets()  # 替代泛化润色
  CvTrimmer.trim()       → kernel.validate_claim() 过滤非 ready 条目
  LatexRenderer.render() → 仅渲染 gate_status=ready 的 bullets
```

**禁止事项（铁律 4）**：①禁止引擎层直接改写事实（改写在内核层完成并经 ClaimGate）；②禁止内核层承担渲染/匹配职责；③禁止绕过 ClaimGate 渲染未确认内容。

## 7. Oracle 论证修订落实（2026-08-23 · 依据 08_Oracle论证记录 2.5 五条）

### 7.1 Port 契约类型定义与错误语义（Oracle 2.5-1）
- **类型引用**：CanonicalExperience = `14.6 schemas/canonical-experience-v2.schema.json`（activity 原子活动 + responsibility 五字段）；BulletClaim = `14.6 schemas/bullet-claim-v2.schema.json`（dependency_refs + used_facts + gate_status）
- **方法错误语义**：`draft_experience` 返回 `{experience, unknowns(≤5), questions(≤3)}`；`compose_bullets` 返回 gate_status ∈ {ready, needs_confirmation, rejected}——needs_confirmation 条目禁止进入渲染管线；rejected 条目记录 claim_ledger 并丢弃

### 7.2 drafter_reviewer 与内核校验衔接（Oracle 2.5-2 · 防混写唯一漏洞点）
- **写死**：DrafterReviewer 评审产生的修改意见必须回流 `kernel.compose_bullets/rewrite_tier` 重新生成并带 `rewrite_source_traceability`；评审本身**不得直接改写 bullet 文本**；主基线 reviewer 仅作质量门
- 违反即熔断（grep 断言见 7.5）

### 7.3 依赖对齐矩阵（Oracle 2.5-3）
- 步骤 1 改为：先输出**依赖对齐矩阵**（pydantic/llm 网关/httpx 等公共依赖，取兼容版本或命名空间隔离），再在单一 venv 验证全量测试
- **"合并"验收 = 616 + 262 用例在合并库一次跑绿**

### 7.4 主基线 product 现状映射（Oracle 2.5-4）
- L2 表补充：product 已有实现（job_evaluation/cv_trim/rank/salary_benchmark/interview_prep/application_tracker/skill_gap 源码 + 通用 role_packs 4 套）→ 融合后模块 = **复制 + 调用，不重写**（与 05 §2"原样保留 ✅"对齐）

### 7.5 双改写路径残留风险（Oracle 2.5-5）
- 风险表新增：`引擎层泛化润色路径未全量替换 → 双改写路径（引擎直改 + 内核改写）`
- 对策：步骤 3 完成后 grep 断言禁用引擎直改调用（drafter_reviewer 内不得出现改写文本的函数调用），并入步骤 6 审计
