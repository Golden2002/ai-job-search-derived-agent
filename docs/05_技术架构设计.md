## 1. 总体架构（三层融合 + MCP 标准件）

```
┌───────────────────────────────────────────────────────────────┐
│ L1 产品化接口层（新增）                                          │
│  Flask API（上传→JD→生成→编辑→导出）+ Web 全链路 + 多格式导出引擎 │
│  （Word/PDF/HTML 三格式一致）                                    │
├───────────────────────────────────────────────────────────────┤
│ L2 通用工作流引擎层（主基线 100%：14.5）                          │
│  JobEvaluator（五维匹配）│ DrafterReviewer（双 Agent 闭环）       │
│  CvTrimmer（相关性加权裁剪）│ LatexRenderer（渲染校验循环）        │
│  AtsChecker（文本层校验）│ TemplateRegistry（多模板 3 风格）       │
│  CareerSuite（面试准备/申请跟踪/技能缺口/薪资基准）               │
├───────────────────────────────────────────────────────────────┤
│ L3 经历处理内核层（辅助基线 100%：14.6）                          │
│  ExperienceDraft（经历拆解方法论）│ ConfirmationGate（事实确认）  │
│  ClaimGate（12 项确定性校验）│ BulletComposer（定向表达）          │
│  RewriteTiers（稳妥/专业/高竞争力三档）│ CapabilityTaxonomy（分类）│
├───────────────────────────────────────────────────────────────┤
│ MCP Server（resume-mcp 升级三原语完整）                           │
└───────────────────────────────────────────────────────────────┘
```

**融合原则（铁律 4）**：L2 与 L3 经**接口契约对接**（`ExperienceKernelPort`），引擎层调内核层产出的"已确认事实 + 三档表达"，不混写实现；内容生成质量由内核层负责（替代主基线泛化润色），流程/渲染/匹配由引擎层负责。

## 3. 核心接口定义

```
POST /api/resume/build            # 全链路：经历+JD → 简历
  in:  {experiences:[], jd, template, tier(稳妥|专业|高竞争力)}
  out: {match:{score, matched[], missing[]}, bullets:[{text, facts_ref, tier}],
        ats:{score, coverage, order, contact}, versions:{conservative, professional, high_impact}}
POST /api/resume/experience/draft # 经历拆解（内核层）
POST /api/resume/experience/confirm # 事实确认（ConfirmationGate）
POST /api/resume/export           # 导出（docx|pdf|html）
GET  /api/resume/versions/{id}    # 三档横向对比
```

**关键契约**：引擎层所有生成必须经内核层 ClaimGate 校验（ready 才可渲染）；数字/责任升级必须来自已确认事实（编造率 0）。

## 4. MCP 插件结构（顶尖标准）

| 原语 | 名称 | 说明 |
|---|---|---|
| Tools | `resume_build(experiences, jd, tier)` | 全链路生成（基线 build 工具升级） |
| Tools | `resume_match(jd, resume)` | JD 匹配评分 + 缺失项 |
| Tools | `resume_draft_experience(text)` | 经历拆解（内核层） |
| Tools | `resume_rewrite(text, tier)` | 三档改写（ClaimGate 校验） |
| Tools | `resume_ats_check(pdf_path)` | ATS 校验 |
| Resources | `resume_templates://{id}` | 模板库 |
| Resources | `resume_role_packs://{id}` | 角色包配置 |
| Prompts | `resume_build_workflow` | 生成工作流模板 |
| Prompts | `resume_experience_intake` | 经历摄入模板 |

## 5. 数据模型

```
ResumeBuild { id, ts, jd, match:{score, matched, missing}, tier,
              sections:[{title, bullets:[{text, facts_ref[], gate_status, tier}]}],
              ats:{score, coverage, order, contact_ok}, versions:{...} }
CanonicalExperience（辅助基线 schema 原样保留）
BulletClaim（辅助基线 schema 原样保留）
```

## 6. 部署形态

- 独立库（Python 3.10+）+ MCP Server（stdio）+ Flask Web（独立端口，基线 5123）
- LaTeX 可降级（无 TeX 环境用 WeasyPrint）；LLM 可注入可离线（内核层确定性回退）
- 嵌入：主 Agent 调用（JD → 简历 → 导出串联）
