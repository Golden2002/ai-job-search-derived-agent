| 维度 | 行业顶尖能力（Rezi/WonderCV/Kickresume） | 量化指标 |
|---|---|---|

| 事实校验 | 表述基于真实经历；不编造不浮夸；信息边界标注 | 编造率 0 |
| 多格式导出 | Word/PDF/HTML 三格式，排版专业 | 3 格式一致 |
| 网页端全链路 | 上传经历→目标岗位→生成→在线编辑→导出 | 完整闭环 |
